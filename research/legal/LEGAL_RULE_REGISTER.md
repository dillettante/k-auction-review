# 법률 규칙 등록부 — Phase 3 핵심 검증본

상태: 연구·설계용 초안 · 2026-08-15 검증 · 공개 배포 전 재검증 필요

이 등록부는 사건별 결론을 대신하지 않는다. `문서에서 확인된 사실`과 `공식 원문`을 연결할 때 사용할 규칙 후보를 정리한 것이다. 법령의 적용 버전은 권리 설정일·경매개시등기일·배당요구 종기 등 사건별 기준시점으로 다시 확인해야 한다. 금액 기준과 경과규정은 특히 현행 조문만으로 판정하지 않는다.

## 운용 상태

| 상태 | 의미 |
| --- | --- |
| `extract_only` | 문서에서 사실을 추출·대조할 수 있으나 권리효과는 결정하지 않는다. |
| `flag_only` | 요건 또는 예외가 사실관계에 민감하므로 경보·질문만 만든다. |
| `conditional` | 모든 필수 사실과 해당 시점의 법령 원문이 확인된 경우에만 조건부 설명을 허용한다. |

모든 규칙의 공통 요건은 증거 ID, 문서 발급일 또는 작성일, 적용 기준일이다. 어느 하나라도 없으면 `finding.conclusion_status`는 `withheld`다.

## 핵심 규칙

### LR-PROC-01 — 법원 문서군 완전성 및 충돌 게이트

- 연결 이슈: IA01, IA04, IA05
- 상태: `extract_only`
- 공식 근거: 민사집행법 제84조(배당요구의 종기 결정·공고), 제85조(현황조사), 제97조(최저매각가격), 제105조(매각물건명세서)
- 입력 사실: 사건·물건내역, 매각물건명세서, 현황조사서, 감정평가서, 최신 등기사항증명서의 문서일·페이지·정정 이력
- 처리: 같은 물건·점유자·권리·면적에 대한 기재를 비교하고 누락·상충·정정 가능성을 `conflicts` 또는 `missing_items`로 기록한다.
- 출력 제한: 문서 간 불일치를 임의로 해소하거나, 명세서 기재만으로 권리의 존속·소멸을 확정하지 않는다.

### LR-REG-01 — 매각에 따른 등기권리 효과의 검토 경보

- 연결 이슈: IA02, IA06
- 상태: `flag_only`
- 공식 근거: [민사집행법 제91조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1013689565)
- 규칙 요지: 저당권 등 담보물권, 대항 가능한 지상권·지역권·전세권·등기된 임차권 및 유치권은 같은 조문 안에서도 매각 조건·대항 가능성·배당요구·성립 요건에 따라 취급이 달라질 수 있다.
- 입력 사실: 권리의 정확한 등기 문구, 접수 순위, 대상 부동산, 경매개시 관련 등기, 말소·이전·본등기 등 후속 기록, 매각조건·명세서.
- 처리: 시간축과 권리종류를 표시하고, 선행권리·보전등기·특별매각조건이 있으면 해당 권리를 `review_required`로 올린다.
- 출력 제한: “말소기준권리”라는 라벨, 접수일 하나 또는 요약 경매지의 표기만으로 소멸·인수를 자동 결론 내리지 않는다.

### LR-LEASE-01 — 주택 임차인의 대항요건 사실 확인

- 연결 이슈: IA03
- 상태: `conditional`
- 공식 근거: [주택임대차보호법 제3조제1항](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031734299), [제3조의2](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1031734145)
- 입력 사실: 주택의 인도와 주민등록, 임대차의 당사자·목적물·보증금, 각 사실의 일자와 그 증거, 소유관계·경매 절차 기준일. 실제 점유는 인도·계속성을 판단하는 사실이며 주민등록을 대체하지 않는다.
- 처리: 각 요건 사실과 일자를 별도 필드로 보여 주고, 시간축상 확인 여부만 산출한다.
- 출력 제한: 실제 점유와 주민등록의 계속성, 가장임대차, 목적물 동일성, 대항 가능 시점은 문서만으로 불명확할 수 있다. 해당 사실이 빠지거나 충돌하면 대항력·인수 여부는 `withheld`다.

### LR-LEASE-02 — 우선변제·최우선변제의 추가 검토

- 연결 이슈: IA03, IA04
- 상태: `flag_only`
- 공식 근거: 주택임대차보호법 제3조의2, [제8조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027302851) 및 주택임대차보호법 시행령 제10조
- 입력 사실: 확정일자, 대항요건의 충족일, 보증금, 경매신청 등기일, 배당요구 종기·신청 내역, 목적물·지역, 적용 시점의 법령 연혁과 부칙.
- 처리: 우선변제 또는 소액임차인 검토에 필요한 날짜·금액·지역·배당 문서가 모두 있는지 점검한다.
- 출력 제한: 현행 시행령의 지역별 보증금·최우선변제액을 과거 사건에 그대로 적용하지 않는다. 배당액·순위의 확정 계산은 MVP에서 하지 않는다.

### LR-DIST-01 — 배당요구 종기와 배당 문서 확인

- 연결 이슈: IA04
- 상태: `extract_only`
- 공식 근거: [민사집행법 제84조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029082491), [제88조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031930621)
- 입력 사실: 법원이 정한 배당요구 종기, 신청·변경·철회일, 채권계산서, 배당표·기일조서, 송달·공고 자료.
- 처리: 문서상 일자를 정렬하고 누락·기한 전후 여부를 표시한다.
- 출력 제한: 권리자별 배당요구 필요성, 유효성, 취하 가능성 또는 실제 배당액은 권리 종류와 절차 진행에 좌우된다. 시간 비교 결과만으로 법률효과를 확정하지 않는다.

### LR-LAND-01 — 집합건물 대지사용권·토지 별도등기 경보

- 연결 이슈: IA01, IA07
- 상태: `flag_only`
- 공식 근거: 집합건물의 소유 및 관리에 관한 법률 제20조
- 입력 사실: 전유부분·대지권 표제부, 토지 등기사항증명서, 대지사용권의 종류와 비율, 별도등기, 규약·공정증서, 매각 범위·특별매각조건.
- 처리: 토지 등기부가 누락되었거나 대지권 미등기·별도등기·전유부분과 토지의 매각범위 불일치가 있으면 분석을 중지하고 자료 요청을 만든다.
- 출력 제한: 건물만의 등기나 감정가만으로 대지사용권의 귀속·소멸을 자동 판정하지 않는다.

### LR-LIEN-01 — 유치권 신고·점유·피담보채권 경보

- 연결 이슈: IA08
- 상태: `flag_only`
- 공식 근거: 민법 제320조·제328조, 민사집행법 제91조제5항
- 입력 사실: 유치권 신고 여부, 피담보채권의 원인·발생·변제기, 목적물 관련성, 점유 개시·계속성·이전 여부, 경매개시 관련 등기일, 공사·수리 자료, 관련 소송·판결.
- 처리: 유치권이라는 문구 또는 신고를 독립된 “주장”으로 기록하고, 핵심 요건 자료의 존재·부재만 표시한다.
- 출력 제한: 유치권의 성립·소멸, 매수인 부담 채무액, 점유의 적법성은 자동 판정하지 않는다.

### LR-SUPERFICIES-01 — 법정·관습법상 지상권 가능성 (기존 통합 규칙)

- 연결 이슈: IA09
- 상태: `flag_only` (새 사건은 아래의 `LR-STATUTORY-SUPERFICIES-01` 또는 `LR-CUSTOMARY-SUPERFICIES-01`로 분리한다.)
- 공식 근거: [민법 제366조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=900141458)
- 입력 사실: 토지·건물 각 소유자와 변동 이력, 담보권·압류 설정 당시의 소유 동일성, 건물의 존재·멸실·신축, 각 매각범위와 매각 조건, 토지·건물 전체 등기·건축물 자료.
- 처리: 토지와 건물의 소유관계가 분리되었거나 역사 자료가 부족하면 전문 검토 경보와 과거 자료 요청을 만든다.
- 출력 제한: 토지·건물의 현재 소유자가 다르다는 사실만으로 법정 또는 관습법상 지상권의 성립·범위를 자동 결론 내리지 않는다.

### LR-PROTECT-01 — 가등기·가처분 등 보전등기 후속기록 확인 (기존 통합 규칙)

- 연결 이슈: IA06
- 상태: `flag_only` (새 사건은 아래의 가등기·가처분 분리 규칙으로 기록한다.)
- 공식 근거: 민사집행법 제91조제3항·제4항
- 입력 사실: 보전등기의 원인·내용·접수 순위, 본등기·판결·말소·배당요구 등 후속 기록, 매각물건명세서·특별매각조건.
- 처리: 해당 등기의 원문과 후속기록이 모두 제출되었는지 확인하고, 없으면 분석 질문으로 출력한다.
- 출력 제한: “가등기”나 “가처분”이라는 명칭만으로 담보가등기 여부, 매수인 대항 가능성, 말소·인수를 결론 내리지 않는다.

### LR-LEASE-SCOPE-01 — 주택·상가 임대차 적용법 분기

- 연결 이슈: IA03, IA04
- 상태: `extract_only`
- 공식 근거: 주택임대차보호법 제3조·제3조의2·제8조, 상가건물 임대차보호법 제3조·제5조·제8조
- 입력 사실: 목적물의 실제·공부상 용도, 주거·상가·혼합 사용 여부, 임차인의 지위, 인도·주민등록 또는 사업자등록·확정일자 관련 자료.
- 처리: 적용 법률이 주택인지 상가인지 또는 혼합·불명인지 명시한다. 불명인 경우에는 해당 보호법상 순위·인수금액 계산을 멈춘다.
- 출력 제한: 주택용 규칙을 상가에, 상가용 규칙을 주택에 적용하지 않는다. 용도 또는 적용법이 불명인 임차인을 ‘대항력 있음/없음’으로 단정하지 않는다.

### LR-PROVISIONAL-OWNERSHIP-01 — 소유권이전청구권 보전 가등기 확인

- 연결 이슈: IA06
- 상태: `flag_only`
- 공식 근거: 민사집행법 제91조, 관련 가등기·본등기 판례
- 입력 사실: 가등기의 정확한 원인·목적·접수순위, 기초계약, 선행 담보권·압류, 본등기·말소·판결·화해 등 후속기록, 매각조건.
- 처리: 소유권이전청구권 보전 가등기로 보이는 경우에도 원인과 후속기록을 별도 수집하고, 선행권리와의 관계를 검토대상으로 표시한다.
- 출력 제한: 가등기 명칭만으로 소멸·인수 또는 매수인의 소유권 상실을 결론 내리지 않는다.

### LR-PROVISIONAL-SECURITY-01 — 담보가등기·청산절차 확인

- 연결 이슈: IA06
- 상태: `flag_only`
- 공식 근거: 가등기담보 등에 관한 법률 제3조·제4조·제13조부터 제15조, 민사집행법 제91조
- 입력 사실: 가등기 원인·피담보채권·변제기, 청산통지·청산금·청산절차, 경매신청·개시 관련 등기와의 선후, 본등기·말소 등 후속기록.
- 처리: 담보가등기 가능성을 추정하지 말고, 청산절차 및 경매와의 시간관계를 확인할 자료 요청을 만든다.
- 출력 제한: ‘담보가등기’라는 추정만으로 매각 효과나 청산금·인수 여부를 계산하지 않는다.

### LR-INJUNCTION-01 — 처분금지가처분 원문·후속기록 확인

- 연결 이슈: IA06
- 상태: `flag_only`
- 공식 근거: 민사집행법 제91조, 가처분 등기·본안소송 관련 공식 기록
- 입력 사실: 가처분 등기 원문, 피보전권리·주문, 접수순위, 본안 판결·취하·말소·이전등기 등 후속기록, 매각조건.
- 처리: 주문과 후속기록을 확보할 때까지 보전등기 경보를 유지한다.
- 출력 제한: ‘가처분’이라는 표제만으로 매수인 대항 가능성이나 소멸을 결론내리지 않는다.

### LR-STATUTORY-SUPERFICIES-01 — 민법 제366조형 법정지상권 검토

- 연결 이슈: IA09
- 상태: `flag_only`
- 공식 근거: 민법 제366조
- 입력 사실: 저당권 설정 당시 토지·건물의 소유관계, 당시 건물의 존재·동일성, 이후 철거·재축·증축, 토지·건물의 매각범위 및 특별매각조건.
- 처리: 기준권리 설정 당시의 역사자료를 시간축으로 표시한다.
- 출력 제한: 현재 토지·건물 명의가 다르다는 사정 또는 건물 현존만으로 성립을 결론내리지 않는다.

### LR-CUSTOMARY-SUPERFICIES-01 — 관습법상 법정지상권 검토

- 연결 이슈: IA09
- 상태: `flag_only`
- 공식 근거: 대법원 전원합의체 판례로 형성된 법리
- 입력 사실: 토지·건물 동일 소유 상태, 분리 처분의 원인·시점, 건물 존속, 사용관계·특약·당사자 의사, 전체 등기·건축물 자료.
- 처리: 저당권 실행형 사실과 구별하여 분리 처분의 경위를 기록한다.
- 출력 제한: 민법 제366조형 요건을 그대로 대입하거나, 분리 소유만으로 성립을 결론내리지 않는다.

### LR-SHARE-AUCTION-01 — 공유지분 매각·공유관계 경보

- 연결 이슈: IA01, IA06
- 상태: `flag_only`
- 공식 근거: 민사집행법 제139조·제140조, 민법 제263조·제268조
- 입력 사실: 매각 지분의 정확한 비율, 다른 공유자·점유자·사용수익 약정, 공유자 우선매수 신고와 기일기록, 분할소송·협의 경과.
- 처리: 일부 지분만 매각되는지와 공유관계 해소 전제의 비용·기간을 별도로 표시한다.
- 출력 제한: 지분 낙찰을 특정 호실·토지의 단독 사용권 취득으로 표현하지 않는다. 공유자 관계와 점유가 불명인 경우 자동 입찰 후보를 제시하지 않는다.

## 배포 전 필수 재검증

1. 각 조문의 연혁·부칙을 사건의 기준일로 대조한다.
2. 판례는 대법원 종합법률정보 또는 국가법령정보센터 원문으로 사건번호·선고일·판시사항을 다시 대조한다.
3. 규칙 엔진에 넣는 모든 단정 문구는 독립된 자동화 테스트와 반례 카드가 있어야 한다.
4. 법령·판례 변경을 탐지할 갱신일과 검토 책임자를 메타데이터로 남긴다.
